# AI Chat Hub
One chat for Claude, ChatGPT, Gemini, Perplexity and Grok through your logged-in accounts. No server, no API keys.
- `android/` – Android app (GeckoView). Build: GitHub Actions → Build APK.
- `extension/` – PC browser extension (Chrome/Edge/Brave/Firefox) with its own chat window.
- `web/` – download page (detects Android / PC). Deploy on Vercel: Framework Other, Output Directory `web`, no build/install command.
