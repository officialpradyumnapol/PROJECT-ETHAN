AI CHAT HUB

One chat for Claude, ChatGPT, Gemini, Perplexity and Grok. It sends your command to the real site and brings the reply back. No server, no API keys.

⬇ DOWNLOAD ANDROID APP (APK)
  1. Open the downloaded file. If Android asks, allow install unknown apps for your browser.
  2. Open the app, pick a provider (for example ChatGPT) and tap BROWSER.
  3. Log in to the site once, then tap DONE.
  4. Type a command in the chat. The app sends it to the site and shows the reply.

Download link works after the APK has been built in GitHub (Actions → Build APK).

⬇ DOWNLOAD PC EXTENSION (ZIP)
  1. Unzip the file into a folder.
  2. In Chrome, Edge or Brave open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
  3. Tap Load unpacked and choose the folder.
  4. Click the extension icon, tap OPEN AI SITES and log in to each site once.
  5. Type a command in the chat window. It goes to the site and the reply comes back.

Firefox: rename manifest.firefox.json to manifest.json, then use about:debugging → This Firefox → Load Temporary Add-on.

iPhone and iPad are not supported.
